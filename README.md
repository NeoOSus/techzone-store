# TechZone - Electronics Store Website

## Topic
Online electronics / tech store website.

## Description
A simple multi-page responsive website for a tech store. Built with HTML5, CSS3, and Bootstrap 5.

## Pages
1. **Home** — Welcome section, features (Flexbox), popular products
2. **About** — Store info, lists of products and services
3. **Products** — Product cards (Bootstrap grid), comparison table
4. **Gallery** — Photo gallery (CSS Grid)
5. **Contact** — Contact form, store info

## Features
- Semantic HTML5 (nav, main, section, footer)
- Headings, paragraphs, lists, links, images
- Table with thead, tbody, tfoot (products.html)
- Form with input, select, textarea (contact.html)
- CSS Flexbox (features section)
- CSS Grid (gallery)
- Positioning: relative + absolute (sale badge)
- Bootstrap grid system (row, col-md-*)
- Bootstrap utilities (spacing, text, buttons)
- Media queries for tablet (768px) and mobile (576px)

## Technologies
- HTML5
- CSS3
- Bootstrap 5

## How to Run
Open `index.html` in a browser.
